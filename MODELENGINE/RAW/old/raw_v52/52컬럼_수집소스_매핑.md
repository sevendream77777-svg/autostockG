## 10년 데이터 수집 전략

### Phase 1: 안정적 소스 (PyKRX + DART + FRED)
```
컬럼 1~17: PyKRX (가격/유동성/메타) - 100% 커버
컬럼 18~29: PyKRX (수급) - 100% 커버
컬럼 30~41: DART (재무) - 분기별, 직전값 forward-fill
컬럼 42~52: FRED/ECOS/FDR (매크로) - 일별
```

### Phase 2: 키움 REST 보완
키움 REST API로 추가 검증/보완 가능 항목:
- `ka10001`: name, sector_code, market_cap, eps, bps, per, roe
- `ka10081`: OHLCV (PyKRX 실패시 백업)
- `ka10086`: 외국인/기관 순매수 (PyKRX 검증)
- `ka10059`: 투자자별 세부 (투신/연기금/보험/은행 분리)
